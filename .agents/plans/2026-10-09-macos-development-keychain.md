# macOS 完整客户端开发 Keychain 准入

## 目标与边界

让完整 Flutter 客户端在本机开发签名下启动并验证登录、首页和安全会话。正式 DP Keychain 默认配置、正式权利文件、既有候选及既有凭据保持原状。开发路径显式开启，使用独立服务名，不通过运行时错误自动回退。

## 当前事实与关键未知

完整候选带空 keychain-access-groups 数组，严格验签通过，但缺少有效 profile，系统启动被拒绝。封装器拒绝未验证的非空权利配置。锁定 Darwin 0.3.2 的 containsKey 先查询 synchronizable=true，write 将查询错误转为不存在；同步查询选择 DP 实现，存在首次新增成功而覆盖失败的风险。该风险须实测，不能只用选项或首次读取证明可用。

## 执行与文件所有权

主控独占 secure_store、macOS 开发权利、封装器、测试、PDEC 与治理文件。独立 Agent 只读复核方案和固定源码；实施完成后由未参与实现的审阅者复核。原生 Agent 只有逻辑边界，不宣称硬隔离。

1. 原生合成键探针仅使用固定独立服务名与新 UUID；先核验不存在，再验证同步查询、首次写读、覆盖写读、指定键删除和重复删除。禁止既有业务服务名、批量删除、ACL 或搜索列表修改，输出仅状态码与合成值比对结果。
2. 实测通过后才评估锁定插件的开发配置；若覆盖或删除失败，定位根因后采用有界适配，不试探性更改正式默认。
3. 开发构建独立目录、独立空权利文件、显式开发标记；签后权利精确核对，Core/Supervisor 固定字节不变。没有未验证 embedded profile，不替代正式封装准入。
4. 在完整客户端验证临时合成值、覆盖更新、冷启动、指定键删除，再验证正常登录页/首页和真实开发账户。错误或系统提示取消不得成为成功。

## 验收与回滚

PDEC validate 退出0且 execution_ready=true 后执行探针；Swift 编译与唯一现有 Apple Development 身份签名结果本机捕获，仅公开脱敏状态。探针是原生查询诊断，不替代完整插件、会话和代理验收。合成条目仅清理同次 UUID，不能清理旧凭据。关闭开发开关并恢复原候选入口可回滚；正式发行仍需有效签名、授权链、公证与 Gatekeeper 验证。
