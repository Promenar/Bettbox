# Android 正式候选账户与订阅验收

## 目标与依据

在已安装的正式签名 APK `e7b5a87` 上验证真实登录、订阅获取、节点呈现、冷启动安全存储及 VPN 行为。公开注册要求邮件验证码；服务端已有 4 个用户、2 个套餐、133 个节点，不能将后台在线标记作为转发节点连通性结论。

## 写入与数据边界

- 服务端仅新增带唯一开发标记的验收账户，通过现有 UserService 创建，沿用套餐 1 的权限组。账户有效期 24 小时、流量 64 MiB、限速 5 Mbps、设备限制 1；管理员、员工、余额、佣金、邀请归属均为零或空。
- 不更改既有用户、套餐、节点、订单、佣金、注册配置；创建动作不调用邮件或支付服务。创建前后在同一数据库事务内核验既有用户内容摘要和订单、佣金内容摘要一致。
- 随机凭据由非 LLM 本机程序生成，经 SSH stdin 传递；本机独占目录 0700、凭据文件 0600。新目录及文件 FD 清空 ACL 并复核后才写入秘密；祖先目录的可写 ACL 必须在执行前检查。原始远端 stdout/stderr 不回显，公开回执只含固定状态与账户 ID。
- 创建不等同于邮件注册、邀请码归属或返佣验收；这些流程单独保留待验收状态。

## 执行顺序与验收

1. 冻结一次性脚本，由未参与实现的审阅者复核秘密边界、权限、事务不变量与失败恢复。
2. 创建账户并生成公开脱敏回执；SSH 失败或输出不明确时保留本机待定凭据，先只读核对，不重试创建。
3. 使用 UI 树定位正式 APK 登录输入控件。凭据只由本机程序读取并注入；不向模型展示包含凭据的 UI 树、截图或日志。
4. 通过登录后固定文案、订阅数量、错误计数和进程状态验收；有意义的实际测试后再登记冷启动及 VPN 执行证据。

## 回滚与限制

新账户自然到期；如需撤销，按唯一开发标记和已记录 ID 将该账户封禁并清空流量，不删除或操作既有账户。创建失败采用事务回滚；结果不明确不能假定回滚成功。公开下载、真实付款、用户邮件、上游购买不在这项执行中。

## 已验证事实

- 账户 ID 5 创建成功；全部限制经刷新后核验，既有用户、订单、佣金内容摘要不变。凭据只在 `.test/three-platform-release/account-provision/private/`，禁止通过模型或报告读取目录内文件内容。
- 真实 HTTPS 登录、账户、订阅和节点接口均 HTTP 200，订阅未过期，返回 23 个节点。
- 0600 文件继承额外 ACL 的问题由公开 fixture 实际复现，文件及目录 FD 清理通过；两项 P2 独立复审闭合。
- 验证脚本的时钟调用错误实际复现并修正。公开回执为 `docs/validation/2026-10-07-three-platform/android-live-account-validation.json`；界面登录、冷启动和 VPN 尚未由这些接口结果证明。

## 输入法边界与候选验证

正式 APK 实测邮箱输入发生改写，完整比对失败；只读 Android EditorInfo 为 `0x8021`，本机 SDK 验证其包含自动纠错标志 `32768`。快速及逐字输入均未保持完整地址，不将这种观察直接认定为服务端登录失败。

主控独占登录、注册、找回密码三页及 `test/xboard/account_input_test.dart`：邮箱、密码、邀请码禁止纠错、候选建议、智能横线及引号替换，密码显示状态保持相同限制。通过真实 `TextInput.setClient` 配置回归验证边界，公开字符串不提交登录或邮件。8 项测试在修复前失败、修复后通过；完整 Flutter 192 项通过，相关文件静态分析无问题，独立审阅无 P1/P2。智能字符枚举线上格式按当前 Flutter SDK 的字符串表示断言。

正式 APK `e7b5a87` 构建、验签、安装回读一致。原生 EditorInfo `0x800b1` 关闭纠错与建议；中文拼音将 ADB 按键转换为汉字及全角符号，Alphabet 模式下公开 ASCII 和真实邮箱完整匹配，真实登录、账号身份、邀请入口、64 MB 配额与冷启动恢复通过。仅临时调整测试模拟器输入模式及软键盘显示，验证后恢复原设置。公开证据为 `docs/validation/2026-10-07-three-platform/android-e7b5a87-apk-validation.json`。节点呈现、VPN 真实流量、邀请注册闭环与支付另验。
